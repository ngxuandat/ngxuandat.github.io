# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm install
npm run dev       # dev server at http://localhost:4321
npm run build     # static build to dist/ (this is also the only "check": no lint or test setup exists)
npm run preview   # serve the built dist/
```

Pushing to `master` triggers `.github/workflows/deploy.yml` (Node 22, `npm ci`, `npm run build`, deploy to GitHub Pages).

## Architecture

Personal blog on Astro 7 + React 19 + MDX, fully static, deployed to GitHub Pages, served from the root of `https://ngxuandat.github.io` (`astro.config.mjs`: `base: '/'`).

- **Base path:** every internal link and asset URL must go through `url()` from `src/lib/posts.ts` (it prefixes `import.meta.env.BASE_URL`). In Markdown/MDX content, which cannot call `url()`, use root-relative links (e.g. `/media/...`) and percent-encode non-ASCII characters or spaces in file names. If `base` is ever changed from `/`, those links need updating.
- **Posts:** the `posts` content collection (`src/content.config.ts`) loads `src/content/posts/**/*.{md,mdx}`. Post pages are generated by `src/pages/posts/[...slug].astro`, which also computes prev/next links. Use `.mdx` only when a post needs components (e.g. `Callout`, `Curriculum`).
- **Post date and ordering:** the `date` frontmatter is optional. `postDate()` falls back to the `YYYY-MM-DD` prefix of the filename, so keep that prefix. `getPosts()` in `src/lib/posts.ts` is the single source for lists and excludes `draft: true`. `draft: true` posts are not built at all, so they can't be previewed in `dev` or `build`.
- **Non-post pages:** `src/pages/*.astro`, plus `src/pages/resources.md`, which uses the `MarkdownPage` layout (frontmatter `layout`, `title`, `lede`). Site-wide metadata and the nav list live in `SITE` (`src/lib/posts.ts`) and `src/layouts/Base.astro`.
- **React components** (`ThemeToggle`, `Search`, `ReadingProgress`, `Gallery`, `Curriculum`) are islands hydrated with `client:*` directives. Theme is set by an inline script in `Base.astro` before paint, using `localStorage` and a CSS-variable theme in `src/styles/global.css`.
- **Legacy URLs:** the blog was migrated from fastpages. Old URLs are kept alive by `redirects` in `astro.config.mjs` and by `src/pages/markdown/...html.ts`, which emits a real `.html` redirect file because GitHub Pages can't do server redirects. Add one of these when renaming or moving a published post.
- **Static files:** anything users must be able to download or load (images, PDFs) goes in `public/` (`public/images/`, `public/media/`). Files elsewhere, such as `src/media/`, are not served.
